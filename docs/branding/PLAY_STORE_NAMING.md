# DuckPort Play Store naming recommendation

Prepared 8 October 2026. This is a listing draft, not a published listing.

| Surface | Recommended text |
| --- | --- |
| Launcher and in-app name | DuckPort |
| Google Play listing title | DuckPort: ADB & Fastboot |
| Short description | Wireless ADB, Fastboot tools, screen mirroring, and device management. |

The listing title is 24 characters, within Google's 30-character maximum. The short description is within the 80-character limit. The launcher label is an Android app resource; the Google Play title is managed separately in Play Console.

Keep the brand and include accurate feature terms. Use natural descriptions of wireless ADB, shell commands, file management, screen mirroring, and Fastboot rather than repeated keyword lists. The title can help communicate relevance, but it does not guarantee search placement. Google also considers app quality and user response, including ratings and reviews.

## Identity and release distinction

The locally installed debug APK keeps `io.github.rhythmcache.dioxamine` so it updates the existing installation and preserves its data. Before a separate public release, select a unique application ID appropriate to the publisher, configure release signing, and build the release Android App Bundle. An example format is `com.yourbrand.duckport`; this is a placeholder, not a selected or verified ID. Package names are unique and permanent on Google Play.

Branding this development APK does not by itself prepare or publish a production release. The project retains the original upstream author, source links, and licensing notices. Store/domain/trademark availability has not been checked.
